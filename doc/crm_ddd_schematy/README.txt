CRM DDD – paczka schematow

Zawartosc:
1. Schemat glowny DDD CRM: bounded contexty, agregaty, encje, value objecty i komunikacja.
2. Proces 1: Obsluga leada i pipeline sprzedazowego.
3. Proces 2: Zarzadzanie klientem.
4. Proces 3: Planowanie i rejestracja aktywnosci handlowca.
5. Proces 4: Finalizacja sprzedazy i wprowadzanie zamowienia.
6. Proces 5: Obsluga zamowienia przez backoffice.
7. Proces 6: Integracja, fakturowanie, platnosc i aktualizacja raportow.
